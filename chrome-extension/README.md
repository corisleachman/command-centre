# Command Centre Capture Chrome extension

## Install locally

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the `chrome-extension` folder.
6. Open Command Centre V2 once and sign in.

A small **CC** button will then appear at the bottom-right of normal webpages. Click it to open the slide-in capture panel. The page title and URL are filled automatically.

## Updating

After pulling a newer version of the repository, return to `chrome://extensions` and click the refresh icon on the extension card.

## Notes

Chrome does not inject extensions into protected browser pages such as `chrome://settings`, the Chrome Web Store or some PDF viewer pages. Capture works on standard webpages.
